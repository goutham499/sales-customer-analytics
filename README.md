# Sales & Customer Performance Analysis Dashboard

## Overview
This project analyzes sales and customer data to identify revenue trends, regional performance, and customer behavior using SQL, Excel, and Power BI.

## Tech Stack
- SQL (Joins, Subqueries, Aggregations)
- Microsoft Excel (Pivot Tables, VLOOKUP)
- Power BI (Dashboards & Reports)

## Features
- Analysis of 50,000+ sales records
- Monthly and regional revenue trends
- Top products and customer segmentation
- Automated Excel reporting
- Interactive Power BI dashboards

## Use Case
This project supports business teams in making data-driven decisions.
